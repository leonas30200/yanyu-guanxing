# 使用说明（给使用者）

**一句话**：把游戏的存档变成一份**能直接看懂、能直接用**的文件。

本项目在github开源，一切倒狗不得house。

> 如果你只是想"解出存档内容"，不看原理，看完这一页就够了。
> 想了解原理 / 自己改代码，看 [README.md](README.md)（开发者文档）。

---

## 运行环境

| 项               | 要求                                                                                         |
| ---------------- | -------------------------------------------------------------------------------------------- |
| **Python** | **最低 3.8**；**建议 3.11**（本机 `py311` 环境，开发与验证都用它）             |
| 第三方包         | **核心功能只用标准库**，一个包都不装也能跑                                             |
| 可选增强         | `tqdm` 进度条 / `xxtea` 爆破快约 100 倍 / `pyelftools`+`capstone`（只有 `elf` 用） |
| 系统             | Windows / macOS / Linux；从安卓设备取档还需要 adb                                            |

- **最低版本：Python 3.8** —— 低于它直接跑不起来（3.7 及以下不支持）
- **建议版本：Python 3.11** —— 开发和验证用的都是它，只测过这一个版本

### 怎么指定用 python

假设本机的 python == 3.11.11 在 `D:\py311\python.exe`。两种写法，任选一个：

```powershell
# ② 或直接写全路径 —— 不用切环境，最省事
cd yanyu-guanxing
D:\py311\python.exe run.py
D:\py311\python.exe run.py local
```

> **没装 3.8+ 怎么办**：去 [python.org](https://www.python.org/downloads/) 下一个 3.11，安装时**勾上 “Add Python to PATH”**。
> 或者使用 [Anaconda](https://www.anaconda.com/download) 等工具。
> 解释器版本不对时，工具会直接把当前版本和应该怎么跑提示出来。

## 0. 最省事的方式：向导

```powershell
cd yanyu-guanxing
python run.py
```

不带任何参数就进向导，全程只问几句：

```
已导入的存档（默认最新的那条）：        ← 导过档才会出现这一步
  [1] 示例角色　android·s12　2026-10-01 18:28　221 字段
  [2] ＋　导入新存档
请选择: 

   ↓ 选 [1] → 直接打开网页版模拟器，结束

   ↓ 选 [2] → 继续问：

请选择模式：
  [1] local　　—— 本地存档（我有文件 / 从模拟器拉取）
  [2] capture —— 抓包导入（ProxyPin / mitmproxy 的 .har）
请选择: 

本地存档来源：
  [1] 我有存档文件，手动给路径
  [2] 从模拟器 / 设备上拉取（游戏要在运行）
请选择: 

存档文件路径（可直接把文件拖进来）: 

        ↓ 导出完成，问一句：

要打开网页版模拟器吗？
  [1] 打开（默认浏览器，存档自动载入）
  [2] 不打开，直接退出
请选择:
```

几个小优化：

- **打开网页时会自动载入这份存档**，不用再手动选文件。
- 存档**目录**也会进剪贴板（万一要手动导入，粘到文件对话框的地址栏就行）。
- 路径可以**直接把文件从资源管理器拖进窗口**，带的引号会自动去掉。
- 向导也收底层参数：`python run.py --pkg huawei --report`。
- 任何时候敲 `q` + 回车就退出，不会留下半个文件。

> 网页版模拟器在 `yanyu-guanxing\web\index.html`，双击也能直接开。
> 没网也能用（全本地），但存档得在网页里手动导一次。

## 1. 直接敲子命令（向导背后就是它们）

```powershell
cd yanyu-guanxing

# ① adb / 模拟器 / 渠道服 —— 都不用管，工具自己找

# ② 跑一条命令（见下表）
python -m yyjh capture "抓包.har"
python -m yyjh local                 # 不给路径 = 直接去模拟器上取

# ③ 结果在 yanyu-guanxing\output\ 下
```

**手上有什么，就用哪条命令：**

| 你手上有的                                    | 用哪条           | 需要游戏在运行吗 |
| --------------------------------------------- | ---------------- | ---------------- |
| 抓包文件（`.har`，ProxyPin/mitmproxy 导出） | `capture`      | ❌ 不需要        |
| 模拟器里的存档（**安卓**）              | `local`        | ✅**需要** |
| 已经拷出来的`dat.db` 文件（或设备路径）     | `local <路径>` | ✅**需要** |
| 已经解密好的`.json`                         | `rebuild`      | ❌ 不需要        |
| 不确定是哪种                                  | `auto`         | 看情况           |
| 一整个文件夹的存档/抓包                       | `batch`        | 看情况           |

```powershell
python -m yyjh capture "抓包.har"        # 抓包 -> 存档
python -m yyjh local                     # 自己去模拟器上取档（推荐）
python -m yyjh local   "dat.db"          # 或者给个已经拷出来的文件
python -m yyjh rebuild "存档.json"       # 明文 JSON -> 存档
python -m yyjh auto    "随便什么文件"     # 自动判断
python -m yyjh batch   "D:\我的存档"      # 批量
```

## 2. 跑完你会看到什么

```
从抓包导出存档
  输入: 抓包.har
  账号: 185438789@163.com（ios，26 服）

──────────────────────────────────────────────
✅ 完成：示例角色乙　平台 ios　版本 00073440　223 个字段
──────────────────────────────────────────────
  输出目录   yanyu-guanxing\output\ios-s3-示例角色乙\20261001-160805\
  存档文件   dat.db
  明文数据   dat.json
  元信息    dat.meta.json
```

**三个文件分别是什么：**

| 文件              | 是什么                                             | 怎么用                                                              |
| ----------------- | -------------------------------------------------- | ------------------------------------------------------------------- |
| `dat.db`        | **存档文件**（游戏能读的格式）               | 直接拖进**存档工具** / 替换游戏里的`dat.db`（名字都不用改） |
| `dat.json`      | **明文数据**（全部存档内容）                 | 用记事本/VSCode 打开就能看，也能改                                  |
| `dat.meta.json` | 元信息（账号、版本、用了什么密钥、什么时候生成的） | 存档多了以后方便对号入座                                            |

### `dat.db` 默认就是「存档工具」能读的那种

不用改名、不用转换，**直接拖进去就能识别**：

- 工具：`data\存档工具\烟雨江湖 · 本地存档工具.htm`（双击开）
- 正文用 **v1.8 格式**（平台固定密钥），这是工具唯一无需额外信息就能解开的格式
- 文件名就叫 `dat.db` —— 工具靠文件名判断版本，这个名字刚好命中 v1.8

> 想换成"按存档版本的内层密钥"（给以后魔改工具用），加 `--save-format current`。
> 两种格式自己能读写，但工具只认 v1.8。

### 目录长什么样：一次跑 = 一个快照目录

**只有这一种结构**（没有开关可调）：

```
yanyu-guanxing\output\
├── ios-s3-示例角色乙\                 ← 第一层：平台-区服-角色名
│   ├── 20261001-160805\          ← 第二层：跑的时间（yyyymmdd-hhmmss）
│   │   ├── dat.db
│   │   ├── dat.json
│   │   └── dat.meta.json
│   └── 20261001-171233\
│       └── ...
├── android-s12-示例角色\
│   └── 20261001-165334\
│       └── ...
└── _cache\                       ← 工具的中间产物（内存候选缓存），不用管
```

两层目录各自回答一个问题：

```
ios-s3-示例角色乙 \ 20261001-160805
 │   │   │            └─ 什么时候跑的（同一秒重跑会给 …-2、…-3）
 │   │   └────────────── 角色名
 │   └────────────────── 区服（存档里的服号，s3 = 3 服）
 └────────────────────── 平台（android / ios）
```

**为什么里面文件名固定叫 `dat.db`：**

- 推回设备时不用改名 —— `adb push …\dat.db /data/data/…/server12/dat.db` 就完了
- 想备份/分享/打包，整个快照目录拿走即可，不用挑三个带时间戳的文件
- 撞名只在**目录名**上处理，里面的文件名永远干净

> **账号不写进任何名字**（邮箱/QQ/微信都是敏感信息），它只存在 `dat.meta.json` 里。

只想换个地方放（结构不变）：

```powershell
python -m yyjh local --outdir "D:\我的存档"    # 换根目录
python -m yyjh local --name 小号A               # 换掉第一层目录名
```

## 3. 关于"需要游戏在运行"

**只有 `local` 一定需要**，`capture` 顺手做（失败也不影响结果）。

原因是游戏有个「外层密钥」，**每个账号一把、随机生成、只存在游戏运行时的内存里**，
不运行游戏就找不到它。工具会在你跑命令时自动去内存里把它挖出来。

挖到之后会**记住**（存在 `keys.user.json`），同一个账号以后就不用再挖了。

如果你手上已经知道这把钥匙，也可以直接给：

```powershell
python -m yyjh local "dat.db" --outer-key 0123456789abcdef
```

**不想让它碰内存？** 加 `--mem off`：

```powershell
python -m yyjh capture "抓包.har" --mem off
```

## 4. 存档文件在哪

**安卓**（需要 root 或模拟器的 adb），存档在：

```
/data/data/com.lanjing.yanyu.lanjing/files/<账号目录>/server<服号>/dat.db
```

### 但是不用自己拷（推荐）

```powershell
python -m yyjh local
```

不给路径，工具就自己去模拟器上找、自己拉回来：

```
从设备取存档导出
  设备: 127.0.0.1:7555（SM-S9210）　官服（com.lanjing.yanyu.lanjing）

请选一个（默认 = 最近改动的那个）：
  [1] 服 58   角色 翟阮天      0.1 MB   最后修改 10-01 14:14   id 7cac3db1…
  [2] 服 12   角色 示例角色      2.7 MB   最后修改 10-01 14:11   id 01234567…
  （直接回车 = [1]；q + 回车 = 退出，什么都不做）
请选择:
```

三个好处：

1. **会把 `dat.db-wal` 一起拉** —— 手动拷最容易漏它，一漏拿到的就是旧数据
2. 多个账号/服的时候列出来让你挑，而且显示的是**角色名**
   （存档里的 `id` 是 `md5(账号)`，光看它认不出是哪个号）
3. 按**修改时间从新到旧**排，还带**最后修改时间**
   —— 同一个模拟器上常常堆着一堆旧存档，看时间就知道哪个是你现在在玩的

这台单子怎么退：

| 你想干什么             | 怎么敲                                 | 结果                                 |
| ---------------------- | -------------------------------------- | ------------------------------------ |
| 选最近玩的那个         | 直接回车                               | 用 [1]                               |
| 选别的                 | 敲编号，回车                           | 用那个                               |
| **不导了，退出** | 敲`q` 回车（`quit`/`exit` 也行） | 直接结束，**不会生成任何文件** |
| 强制中断               | `Ctrl+C`                             | 直接结束，不会帮你默认选一个         |

### 其它三种输入也支持

```powershell
python -m yyjh local "dat.db"                                  # ① 已经拷出来的本地文件
python -m yyjh local "/data/data/…/server12/dat.db"            # ② 设备路径（直接粘）
python -m yyjh local "127.0.0.1:7555:/data/data/…/server12/dat.db"  # ③ 指定设备
```

第②种就是你在模拟器里（MT 管理器之类）看到什么路径就粘什么，不用先想文件名。
路径带空格或被引号包住都没关系。

> ⚠️ **iOS 走不了这条路** —— iOS 没有模拟器，拿本机存档要越狱。
> iOS 请用 `capture` 抓包，那条路线**免越狱**（接口是明文 HTTP，连证书都不用装）。

## 5. 渠道服 / 模拟器 / adb —— 谁管？

**结论：都不用你设置。** 但下面三件事说清楚，省得你怀疑是工具的问题。

### 5.1 渠道服（华为/小米/B站/4399…）—— 你不需要知道自己是哪个渠道

不同渠道的游戏**包名不一样**（官服 `com.lanjing.yanyu.lanjing`，华为服
`com.lanjing.yanyu.huawei`，以此类推），存档格式完全相同。

**最常见的麻烦**：模拟器上可能同时装了官服 + 华为服 + B站服，
而你根本分不清自己那号在哪个里面。工具的处理顺序：

1. **自动反查（首选）** —— 拿你这个号算出来的 `md5(账号)`，去设备上
   每个渠道的 `dat.db` 里搜一下，搜到就是在那个包里。
   **你不用提供任何信息**，也不需要知道渠道叫什么。
2. 你上次选的（已在 `keys.user.json` 里）
3. 只有一个在运行 → 就用它（你一般在看着它）
4. 还是分不清 → 直接弹个单子让你选：

   ```
   这台设备上装了 3 个渠道的游戏，请选一个（你正在玩的那个）：
     [1] 官服      com.lanjing.yanyu.lanjing    运行中(17695)  服 12/20
     [2] 华为      com.lanjing.yanyu.huawei                     服 12
     [3] B站       com.lanjing.yanyu.bilibili                   服 7
   （直接回车 = [1]；选定后再跑就会记住了；
     也可以一劳永逸：加 --pkg <渠道名>，例如 --pkg huawei）
   请选择:
   ```

   单子里特意写了**服号** —— 光看包名认不出来，看服号就认得。

固定下来以后就不用再选了：

```powershell
python -m yyjh local "dat.db" --pkg huawei           # 按渠道名
python -m yyjh local "dat.db" --pkg 华为             # 中文名也行
python -m yyjh local "dat.db" --pkg com.xxx.yyy.zzz   # 直接写包名
python -m yyjh local "dat.db" --no-pick              # 不弹单，取第一个
```

看设备上到底装了哪几个渠道（含服号、存档数、是否在运行）：

```powershell
python -m yyjh mem pkgs
```

> **没收录的渠道也能用** —— 只要有包名能扫到就行，
> 密钥算法跟渠道无关（受影响的只有内层密钥后缀，见 §9）。

### 5.2 模拟器（MuMu / 雷电 / 夜神 / 蓝叠 / 真机）—— 自动找

不用填 serial。工具会列出现有设备，**挑装了游戏的那台**用。

```powershell
python -m yyjh mem devices
```

输出长这样（两台设备时）：

```
在线设备 2 台（按优先级排）：
  127.0.0.1:7555       SM-S9210         root     官服（com.lanjing.yanyu.lanjing）
  emulator-5558        SM-S9210         root     官服（com.lanjing.yanyu.lanjing）
```

常见模拟器的 serial 工具都知道（会自动优先选）：

| 模拟器   | 常见 serial                               |
| -------- | ----------------------------------------- |
| MuMu     | `127.0.0.1:7555` / `127.0.0.1:21503`  |
| 雷电     | `emulator-5554` / `127.0.0.1:5555`    |
| 夜神     | `127.0.0.1:62001` / `127.0.0.1:62025` |
| 蓝叠     | `emulator-5554` / `127.0.0.1:5555`    |
| 通用 AVD | `emulator-5554` / `emulator-5558`     |
| 真机     | 一串字母数字（如`R58M12345AB`）         |

想指定某台：

```powershell
python -m yyjh local "dat.db" --serial 127.0.0.1:7555
```

> 多开（一台模拟器开多个实例）也能用 —— 哪台开了游戏就用哪台。

### 5.3 adb 在哪 —— 自动找，找到就记住

以前要你手填 adb 路径，现在**不需要了**。工具按这个顺序找：

1. 命令里的 `--adb 路径`
2. 环境变量 `YYJH_ADB`
3. `keys.user.json` 里上次记住的
4. 系统 `PATH`（装过 platform-tools 且加过环境变量）
5. 常见安装位置：MuMu / 雷电 / 夜神 / 蓝叠自带的 adb，
   `C:\platform-tools`、`D:\platform-tools`、`%LOCALAPPDATA%\Android\Sdk` …
6. 还找不到，就在 `C:\` `D:\` `桌面` 等目录里浅层搜一下 `platform-tools\adb.exe`

**找到之后会记进 `keys.user.json`**，下次直接用，不再搜。

还是想自己指定：

```powershell
python -m yyjh mem devices --adb "D:\平台工具\adb.exe"
# 或（永久生效）
$env:YYJH_ADB = "D:\平台工具\adb.exe"
```

> 什么情况下会失败？**adb 版本太旧**（要用 1.0.41 以上，模拟器自带的都够新）、
> 或者 `adb devices` 里一台设备都没有（模拟器没开 / 没开 ADB 调试）。

## 6. 抓包怎么抓（推荐流程）

**一句话：先在游戏里退出登录 → 开抓包 → 重新登录 → 上传存档 → 停抓包。**

1. 游戏里**退出登录**（回到登录页 / 选择账号那一步）
2. **开始抓包**（ProxyPin 点开始；mitmproxy 则先跑起来）
3. 回游戏**重新登录**，进到角色里
4. 设置里**上传一次存档**（“上传存档 / 云存档”）
5. **停止抓包**，导出成 `.har`
6. 跑 `python -m yyjh capture "抓包.har"`

> 顺序别弄反：**退出登录要在开抓包之前**。
> 否则登录过程没被录到，就拿不到登录响应里下发的密钥，会报 `没找到带 k 的响应`。

### HTTPS 不要开

- 存档上传走的是**明文 HTTP**，**安卓和 iOS 都一样** —— 不开 HTTPS 完全够用，
  还省了装证书这一步。
- 一旦开了 HTTPS 解密，游戏里的 **QQ / 微信登录会走不通**（证书不被信任），
  **你就登不进去了**。
- 有些抓包工具会强制开 HTTPS。那就务必把 **`qq.com`（和 `weixin.qq.com`）
  加进 HTTPS 例外**，否则一样登不上。

### 想少抓噪音：也可以“登录成功之后再开抓”

熟悉流程的话，可以让游戏先停在登录页，**确认登录成功之后再点开始抓包**，
接着照样“进角色 → 上传存档”。

- 好处：抓包文件小很多，不含登录前的杂请求。
- 代价：**吃手速** —— 登录请求发得很快，慢一步就漏掉 `k`。
- 拿不准就别这么干，老老实实按上面 6 步走。

### 其它

- 一个抓包里通常有多个 upload，工具会**自动挑最大的那个**（那才是完整存档）。
- iOS 走这条路**免越狱**：接口是明文 HTTP，连证书都不用装。

## 7. 出问题了对照这张表

| 提示                           | 什么意思                   | 怎么办                                                      |
| ------------------------------ | -------------------------- | ----------------------------------------------------------- |
| `没找到 upload 请求`         | 抓包里没有存档上传         | 在游戏里手动上传一次再抓                                    |
| `没找到带 k 的响应`          | 抓包没覆盖到登录过程       | 照 §6 的流程来（**退出登录 → 开抓包 → 重新登录**） |
| `拿不到可用的外层密钥`       | 游戏没运行 / 找不到进程    | **先把游戏打开、进一次角色**，再跑一次                |
| `XXX 没在运行`               | 要导的那个渠道的游戏没开着 | 把它打开、进一次角色（只认正在跑的那个进程）                |
| `设备上没找到 dat.db`        | 没登过号 / 渠道包不对      | 进游戏登录一次、存一次档；或用`--pkg` 指渠道              |
| `连不上设备，没拿到存档`     | adb 里没有可用设备         | 见 §5.2；或改用`local "本地文件"`                        |
| 弹出`请选择:` 单子           | 设备上有多个存档           | 输编号；`q` 退出；无法交互时自动取最新改动的              |
| `已取消，没有生成任何文件。` | 你在单子里敲了`q`        | 正常，没报错                                                |
| 弹出`请选择:` 单子           | 一台设备装了多个渠道       | 输编号，或直接回车；想固定就加`--pkg 渠道名`              |
| `没找到该账号的 dat.db`      | 游戏没在这台设备登录过     | 确认设备和账号；用`--pkg` 指渠道                          |
| `没在任何设备上找到游戏`     | adb 里没设备 / 包名没识别  | 开模拟器；用`--pkg huawei` 指定渠道                       |
| `adb 里没有任何设备`         | 模拟器没开 / 没连上        | 见 §5.2；试`adb connect 127.0.0.1:7555`                  |
| `找不到 adb.exe`             | 没装 platform-tools        | 见 §5.3：`--adb 路径` 或 `$env:YYJH_ADB=...`           |
| `内层密钥不在表里：版本 xxx` | 游戏更新了，密钥表过期     | 见下面「游戏更新了」                                        |
| `认不出这个文件该用哪个接口` | 文件类型不支持             | 只支持`.har` / `dat.db` / `.json`                     |
| 中文显示成乱码                 | 控制台代码页问题           | 一般已自动处理；仍乱码可用`--log 日志.txt` 写文件看       |

**任何报错都加 `-v` 再跑一次**，会显示完整流程和错误堆栈：

```powershell
python -m yyjh local "dat.db" -v
```

想把过程存下来发人看：

```powershell
python -m yyjh local "dat.db" --log 出错了.txt
```

## 8. 游戏更新了怎么办

更新后最常见的报错是 `内层密钥不在表里`。三步解决：

```powershell
# ① 如果手上有第三方导出工具的新版 exe，直接从里面提取密钥表
python -m yyjh exe tables "工具.exe" --save

# ② 没有工具，就等游戏跑起来后用内存挖（外层密钥同理）
python -m yyjh mem crack --db "dat.db"

# ③ 或者手动补一条
python -m yyjh key add 00074000 abcdefghijklmnop
```

然后重新跑 `capture` / `local` 即可。

## 9. 几个名词（看报错时用得上）

| 名词                  | 大白话                                                         |
| --------------------- | -------------------------------------------------------------- |
| **XXTEA**       | 一种加密算法，相当于"带密码的洗衣机"，输入 16 个字符的钥匙     |
| **base64**      | 不是加密，只是把二进制写成文字，谁都能解回来                   |
| **内层密钥**    | 解存档正文用的。**按"版本 + 渠道"固定**，表里查得到      |
| **外层密钥**    | 解本地存档最外层用的。**每个账号一把、随机、只在内存里** |
| **初版 dat.db** | 工具输出的格式：只有一层加密，没有外层密钥                     |
| **抓包 / HAR**  | 把游戏和服务器之间跑的数据拦下来存成的文件                     |

## 10. 还能干点别的

```powershell
python -m yyjh -h              # 看所有命令
python -m yyjh mem devices     # 看设备情况

python -m yyjh info "某文件"    # 看看这是个什么文件
python -m yyjh db show "dat.db" # 看看存档文件的结构（不解密）
```
